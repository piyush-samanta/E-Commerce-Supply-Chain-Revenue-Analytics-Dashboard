# 📊 E-Commerce Supply Chain & Revenue Analytics Dashboard

## 📌 Project Overview
This project presents an interactive Microsoft Excel dashboard designed to analyze e-commerce sales and supply chain performance. The dashboard transforms raw transaction data into meaningful business insights by tracking revenue, orders, returns, product performance, and shipment efficiency.

---

## 🎯 Business Objective
- Monitor overall sales performance.
- Identify top-performing product categories.
- Analyze return trends and reasons.
- Measure shipment efficiency.
- Enable data-driven business decisions through interactive dashboards.

---

## 📈 Key Performance Indicators (KPIs)

| KPI | Value |
|------|--------|
| Total Revenue | **₹1.13M** |
| Total Orders | **4,991** |
| Return Rate | **11.1%** |
| Average Shipment Time | **3.02 Days** |
| Top Revenue Category | **Beauty (~22%)** |

---

## 🔍 Key Insights

- Generated **₹1.13M** revenue from **4,991** customer orders.
- Maintained an overall **11.1% product return rate**.
- **Beauty** was the highest revenue-generating category, contributing approximately **22%** of total sales.
- Major return reasons included:
  - Wrong Item
  - Defective Item
  - No Longer Needed
- Average shipment time was **3.02 days**, indicating efficient order fulfillment.
